# TELINGA / SOUND WITHIN

Komposisi `telinga-volume-vertical`: Bahasa Indonesia, 65 detik, 60 FPS, 1080×1920.

**Belum diekspor ke MP4. Pengguna menentukan kapan render dimulai.** Narasi masih null. Perbaikan sel rambut dan coretan UNDO diperiksa di Studio pada 20,5 dan 47 detik; review seluruh film belum dilakukan.

Memakai GLB headphone nisu (CC0), model telinga luar Innerscene (CC0), dan telinga dalam hasil segmentasi CT dari SPL Inner Ear Atlas (3D Slicer License Part B). Sel rambut, cairan dan sinyal tetap ilustrasi prosedural. Aset beserta provenance dan lisensi disimpan lokal di `public/telinga-volume/models/`; visual belum direview lewat render.

Framing produk dan close-up CT sudah dikoreksi agar batas mesh tidak menabrak area judul/copy. Pemeriksaan proyeksi CPU pada 1.722 frame lolos; lihat [audit framing](../../../docs/telinga-volume/framing-validation.json). Ini bukan review visual.
